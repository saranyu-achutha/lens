Merge rules (duplicate songs)

One song can end up stored twice (spelling variant, longer name, same recording on two songs). Each rule either suggests merges (Review → Duplicate songs, merge a whole rule in one click) or merges automatically during the pipeline. Every merge can be undone under Review → Decision history. Click Save settings after changes.
