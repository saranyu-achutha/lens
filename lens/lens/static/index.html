Spotify chart

India Top 200 (daily and weekly) from charts.spotify.com. Importing needs a session token from a logged-in browser; paste it here when the chart falls behind.

Status

Paste the session token

  1. Open charts.spotify.com and log in.
  2. Press F12, open the Network tab, reload the page, and type charts-spotify-com-service in the filter box.
  3. Click one of those requests; under Request Headers copy only the authorization value (it starts with Bearer BQ…).
  4. Paste it below and click Save and import. The token lasts about an hour; it is saved only on the server and never shown again.

Paste only the authorization value: never cookies or a whole network log, and not in chat.

Merge rules (duplicate songs)

One song can end up stored twice (spelling variant, longer name, same recording on two songs). Each rule either suggests merges (Review → Duplicate songs, merge a whole rule in one click) or merges automatically during the pipeline. Every merge can be undone under Review → Decision history.
